## What was audited

Standard-depth pass over: full backend (all domain packages, `core/`, config,
emails, i18n, `main.py`, auth dependencies), the frontend auth/i18n/routing layer
and component sweep, backend test shape, and CI/tooling presence. The codebase is

**Not audited (disclosed):** individual Alembic migration correctness, each
shadcn/ui primitive, Playwright e2e internals, Docker/Traefik compose hardening,
and a dependency-CVE scan (`pip-audit`/`npm audit` were not run — they need
network).

## Findings considered and rejected

- **localStorage JWT** (`frontend/src/lib/tokenStore.ts`): XSS-exposed, but the
  file documents it as an intentional, one-file-swappable storage choice —
  standard template convention, not a bug. (A move to httpOnly cookies is a
  *direction* option, not a defect.)
- **Committed `.env` with `changethis` placeholders**: by-design for this
  template; `core/config.py` and `auth/config.py` *enforce* non-default secrets
  outside `local`. Not a finding.
- **Devtools rendered unconditionally** (`frontend/src/routes/__root.tsx`):
  ships TanStack Router/Query devtools in the prod bundle — LOW value; a one-line
  `import.meta.env.DEV` gate if it ever matters. Not worth a standalone plan.
- **Password-reset JWT is not single-use** (valid until expiry): standard
  FastAPI-template limitation; note only.
